# Permissions and local data

AFK ALERTS reads live game values to evaluate the alerts you configure. It does not automate gameplay or send chat messages.

- **Optional HTTP permission:** GE alerts request item-price data from the RuneScape service under `https://secure.runescape.com`. Those requests identify the relevant items. GE prices require a network connection and permission; the remote service also receives ordinary connection metadata. Other alert types do not need GE requests.
- **Optional chat permission:** chat alerts compare incoming messages against locally configured phrases. A temporary in-memory picker retains up to 80 messages from the last 60 seconds, with up to 512 characters each. It clears on logout, reload, clock reset or revoked permission. Choosing a message copies its text into your editable trigger phrase; that phrase is saved/shared only when you save the alert or preset. The history itself is not written to presets, the settings database or effect recordings.
- **Consent controls:** both permissions are optional and chosen separately in the native client. Settings → General shows the current access status. Manage permissions sends an explicit native permission request (`ppr rs3_alerts_plugin` for the local installation); it never runs permission-enable commands. No permission dialogs or connection tests are started automatically on startup. A GE request action waits up to 60 seconds for actual HTTP consent before testing one official item price. Revocation cancels active/queued HTTP lookups and disables cached GE readings; chat history clears on revocation. The Plugin Hub padlock is the direct client control if the request command is unavailable or the client rejects a change.
- **Local storage:** alert settings, personal presets, audio choices, window preferences, diagnostic state and an explicitly saved effect recording use the client's PersistentDB. The plugin has no developer telemetry/upload endpoint.
- **Optional recordings:** Settings → Developer starts/stops a bounded effect/vitals recording for troubleshooting. Recording is off by default. It stores named numeric samples and unavailable/gap markers, stops after 20 minutes or its size limit, and stays locally saved for export after a reload. Starting a new saved recording replaces the previous one. Export uses numbered text pages; send it only if you choose to share it. It does not include chat/account/login fields.
- **Preset sharing:** exported codes contain alert/highlight configuration, including any trigger phrases or item/entity names you entered. Codes do not contain custom audio files, received chat, credentials, or diagnostic recordings. Review a code before sharing if your configured phrases are personal.

Removing a preset does not remove its running alerts. Local settings are not remotely deleted by contacting support. Client/plugin-storage management controls depend on the game client. This release does not add an in-plugin recording-deletion control.
