# AFK ALERTS 0.7.0 - Public Test

An early public testing release of configurable audio and visual reminders for RuneScape. Feedback, bug reports and code contributions are welcome.

- Resource thresholds, supported effect timers, chat phrases, inventory space, XP inactivity and owned ground-item drops.
- Personal presets with import/export, including four Gregorovic variants.
- Ten built-in sounds, master/per-alert volume and mute, text popups and persistent red condition bars.
- General, Audio, Sounds and Developer settings tabs. Recording and connection/API diagnostics live under Developer and are optional.
- MIT-licensed source, automated tests and build tools.

**AI disclosure:** I do not know how to code. AI (OpenAI Codex) wrote the implementation, with me supplying the ideas, requirements, in-game testing and feedback. AI also helped with the tests and documentation. Independent code review and contributions from experienced developers are welcome. This release does not claim an independent human audit or completed Jagex review. See AI_DISCLOSURE.md.

Requires **PrettyUI** (mod.io ID **6398181**). Use the installation instructions in README.md. This release has not been approved for Plugin Hub distribution. Many expanded effect bindings, the latest native permissions flow and wider platform behaviour still need feedback.

## Downloads

- `afk_alerts_0.7.0.zip`: installable plugin, with plugin.json and main.lua at the ZIP root.
- `afk_alerts_source_0.7.0.zip`: editable source, tests, build tools and documentation.
- `SHA256SUMS.txt`: checksums for both archives.

Personal clips and converter binaries are excluded. Export existing personal presets before updating. Report issues with the plugin version, platform, steps and console error; remove personal chat/account information before sharing.
