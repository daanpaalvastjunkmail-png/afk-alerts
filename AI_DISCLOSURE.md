# How AFK ALERTS was made

I do not know how to code. AFK ALERTS' implementation was written by AI (OpenAI Codex), following my ideas, requirements and feedback. My role has been to decide what the plugin should do, test it in RuneScape, report problems and refine the behaviour and interface.

AI has also helped write the automated tests, documentation and release tooling. Passing those tests is useful feedback, but it is not an independent human code audit and does not prove every live API binding or platform works. In-game checks and remaining limits are documented in RELEASE_CHECKLIST.md.

This is an early public testing project. Experienced developers are welcome to review the source, explain issues, improve the implementation or contribute fixes. Please do not assume that the code has been independently reviewed just because it is available on GitHub or carries an MIT license.

PrettyUI is an external dependency created by its own author; it is not code produced for this project. RuneScape and Jagex assets and APIs retain their own ownership.

Before a mod.io submission, Jagex requires the submitting creator to personally review and understand the code, including when AI tools were used. The creator's current lack of programming experience is disclosed here, and this project does not claim that requirement has already been satisfied. An experienced developer walking through the implementation with the creator would help address that gap; the creator remains responsible for the submission.

Official policy: https://developer.runescape.com/rs/submission/guidelines.html#ai-policy
